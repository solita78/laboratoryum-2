# LABORATORYUM · VERSIÓN WEB

## Hero
Laboratoryum es un laboratorio independiente de experimentación sobre el futuro de la web.

Investigamos una pregunta de fondo: qué pasa con el sentido, la evidencia y la memoria cuando los contenidos circulan entre personas, plataformas y agentes de IA.

No publicamos opinión aislada. Publicamos pruebas, comparaciones y métodos reutilizables.

## Manifiesto breve
La web ya no vive solo en una pantalla.
Vive en resúmenes, capturas, asistentes, traducciones, automatizaciones, motores de búsqueda y sistemas de archivo.

Por eso, cada experimento de Laboratoryum toma un problema real de circulación digital, lo somete a contraste y produce una salida útil:
- una estructura reproducible,
- un criterio verificable,
- y un kit aplicable a otros proyectos.

## Temporada completa · 25 experimentos

### LAB-001 · La URL que desaparece
**Qué investiga**
Evalúa cómo cambia el acceso y la verificabilidad cuando una URL deja de estar disponible o se reemplaza.

**Pregunta central**
¿Qué pasa con la memoria pública cuando una URL desaparece o cambia de destino?

**Hipótesis de trabajo**
Sin estrategia de preservación y redirección, la evidencia web se vuelve frágil e incitable.

**Salida reutilizable**
Link permanence kit

### LAB-002 · El enlace sin contexto

**Hipótesis de trabajo**
La mayoría de enlaces compartidos sin contexto generan interpretación parcial o errónea.

**Salida reutilizable**
Contextual linking kit
