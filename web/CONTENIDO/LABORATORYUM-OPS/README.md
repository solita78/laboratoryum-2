# Laboratoryum Ops

Estructura operativa para ejecutar y publicar los experimentos LAB-001 a LAB-025.

## Estructura por experimento
Cada carpeta `LAB-00X` incluye:
- `00-brief.md`
- `01-protocolo.md`
- `02-datos.md`
- `03-analisis.md`
- `04-entregables.md`
- `05-publicacion.md`

## Curaduría general
La colección completa se divide en dos capas:
- Base metodológica (`LAB-001` a `LAB-010`): circulación, acceso, evidencia, archivo, trazabilidad de agentes y vigencia temporal.
- Serie aplicada por formato (`LAB-011` a `LAB-025`): texto, imagen, audio, video, entrevista, datos, documentos, social, email, formularios, archivos, bio, obra, mapas y testimonios.

## Regla de cierre por LAB
Un LAB solo se cierra si tiene:
- evidencia reproducible,
- comparación humano/IA (cuando aplique),
- checklist reutilizable,
- producto derivado publicable.
